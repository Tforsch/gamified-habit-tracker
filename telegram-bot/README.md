# ⚔️ HeroQuest Telegram Bot (RPG Habit Companion)

Telegram-бот для гейміфікації звичок і дейліків.

## Функціонал:
- 🧙‍♂️ **Профіль героя**: рівень, динамічні ASCII-смуги HP та XP, стрік.
- ⚔️ **Інтерактивні квести**: виконання дейліків натисканням однієї інлайн-кнопки з нарахуванням досвіду та підвищенням рівня.
- ⏳ **Таймер дедлайну**: підрахунок часу до опівночі (00:00 UTC), коли настає штраф за невиконані завдання.
- 🎲 **Скриня луту**: кидок кубика d20 раз на добу для отримання випадкового досвіду.

## Запуск:
1. Отримайте токен бота у [@BotFather](https://t.me/BotFather) через команду `/newbot`.
2. Запустіть проєкт:
   ```cmd
   dotnet run
   ```
3. Вставте отриманий токен у консоль (або передайте через змінну оточення `TELEGRAM_BOT_TOKEN`).
