# 🌸 Parfyme Bot (Магазин парфумерії)

Telegram-бот для магазину парфумерії на базі **aiogram 3.x**.

## Особливості:
- 💧 **На розпив**: вибір об'єму (3, 5, 10, 15 мл) з автоматичним перерахунком ціни (`ціна/мл * об'єм + вартість тари`).
- 📦 **Цілі парфуми**: каталог із 15 світових брендів (*Tom Ford, Creed, Kilian, Dior, Chanel, MFK тощо*).
- 🖼 **Картка товару**: фото аромату, ноти (верхні, середні, базові), детальний опис та ціна.
- 🛒 **Швидке замовлення**: оформлення через спливаюче сповіщення (`alert`).

## Встановлення та запуск:

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустіть бота:
   ```bash
   python bot.py
   ```

3. Введіть токен від [@BotFather](https://t.me/BotFather) при запиті в консолі (або збережіть його у змінну середовища `BOT_TOKEN`).
